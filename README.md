# E-Commerce Customer Churn Analysis
Python &amp; SQL-based e-commerce churn analysis with Power BI dashboards and DAX measures for retention insights.
Project Overview

This project analyzes customer behavior and churn patterns in an e-commerce platform using SQL for data analysis and Power BI for visualization.
The goal is to identify key factors driving customer churn and provide actionable business insights to improve customer retention.

🎯 Business Objectives

•Identify churned vs retained customer behavior

•Analyze return rate, cart abandonment, and purchase patterns

•Understand gender-based and behavioral differences

•Support data-driven decision making for retention strategies

🗂Dataset Information

‣Source: E-commerce customer dataset (CSV)

‣Records: Customer-level transactional & behavioral data

‣Target Variable: Churned (0 = Retained, 1 = Churned)

🧹Data Cleaning & Preprocessing

●Handled missing values using:

   •Median imputation for numerical columns

   •Business-logic-based assumptions where applicable

●Dropped low-value / highly missing columns

●Converted data types for accurate aggregation

●Stored cleaned data in MySQL database
